# Snapbox — Order & Driver Management System

An OOP project simulating the Snapp Box order-assignment system.

## Structure

- `driver.py` — `Driver` class (the driver)
- `order.py` — `Order` class (the order)
- `delivery_system.py` — `DeliverySystem` class (the system)
- `main.py` — CLI for the Quera problem format
- `test_contract.py` — contract tests (do NOT modify)
- `tests/` — personal unit tests
- `peer_review/` — peer evaluation reports

## Running

```bash
python main.py < input.txt
